(ห้ามใส่ข้อมูลส่วนตัวของใครลงไฟล์ — repo นี้เป็นเว็บสาธารณะ)

## หลักที่ใช้ (ห้ามแต่งโครงเอง)
ส่วนที่เป็น "กติกา" คำนวณด้วย `node horoscope/plan.js <วันที่>` เสมอ ห้ามคิดเอง:
- `days` 8 ช่อง — ทักษาของคนเกิดแต่ละดาว: อาทิตย์ จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ แล้วช่องที่ 8 = **พุธกลางคืน (ราหู)**
  - `todayRole` ดาววันนี้ตกภูมิไหน (บริวาร อายุ เดช ศรี มูละ อุตสาหะ มนตรี กาลกิณี) · `theme` เรื่องเด่นของภูมินั้น · `stars`
  - `luckyColor` (ศรี) · `powerColor` (เดช) · `supportColor` (มนตรี) · `avoidColor` (กาลกิณี) · `luckyNumber` (เดช+ศรี)
- `dayAnimal` นักษัตรของวันนี้ตามปฏิทินจีน · `animals` 12 ช่อง — วันนี้เป็นวันอะไรของคนเกิดปีนักษัตรนั้น (`relation`)
  - วันชง · วันชงเล็ก · วันตรงนักษัตร · วันส่งเสริมมาก · วันส่งเสริม · วันปกติ
- `numbers` เลขประจำวันส่วนตัว 1–9 (แต่ละคนได้เลขไหน หน้าเว็บคิดเองจากวันเดือนเกิด)

**ส่วนที่เขียนเอง** = ข้อความทั้งหมด ต้องเล่าตามกติกาของช่องนั้น
- ทักษา: ภูมิศรี → โชคลาภ เงิน เสน่ห์ · เดช → ความมั่นใจ ผู้นำ · มนตรี → ผู้ใหญ่/คนช่วยเหลือ · บริวาร → คนรอบตัว ทีม ครอบครัว
  · อายุ → สุขภาพ ความสบายใจ · มูละ → บ้าน ทรัพย์สิน การออม · อุตสาหะ → งานหนัก ลงแรงแล้วได้ผล · กาลกิณี → อุปสรรคเล็ก ๆ ใจเย็น (ห้ามขู่)
  · `overall` ต้องบอกว่าดาววันนี้เข้าภูมิอะไร แล้วอธิบายเป็นภาษาคน
- นักษัตร: วันชง → ใจเย็น รอบคอบ เรื่องใหญ่เลื่อนได้ก็เลื่อน (ห้ามขู่) · วันชงเล็ก → เรื่องจุกจิก ระวังเข้าใจผิด
  · วันตรงนักษัตร → พลังของตัวเองเด่น · วันส่งเสริมมาก/ส่งเสริม → ติดต่อคน ขอความช่วยเหลือ เริ่มเรื่องใหม่ · วันปกติ → ทำตามแผน
- เลขประจำวัน: 1 เริ่มต้น · 2 ร่วมมือ · 3 สื่อสาร · 4 ละเอียด เป็นระเบียบ · 5 เปลี่ยนแปลง ยืดหยุ่น · 6 ดูแลคนรอบตัว · 7 ทบทวน อยู่กับตัวเอง · 8 งานและเงิน · 9 เคลียร์เรื่องค้าง ปล่อยวาง

## ไฟล์ที่ต้องเขียนทุกวัน
- `horoscope/YYYY-MM-DD.json` — วันที่ตามเวลาไทย (UTC+7) ของวันที่เพิ่งเริ่ม
- `horoscope/today.json` — เนื้อหาเดียวกันทุกตัวอักษร (หน้าเว็บอ่านไฟล์นี้)
- ถ้าไฟล์วันนั้นมีอยู่แล้ว ไม่ต้องเขียนทับ แค่เช็กว่า today.json ตรงกัน
- ลบไฟล์รายวันที่เก่ากว่า 30 วันทิ้ง (เก็บ today.json · README.md · plan.js · astro.js ไว้เสมอ)

## รูปแบบ
```json
{
  "date": "2026-09-29",
  "todayPlanet": "อังคาร",
  "dayAnimal": "มะเมีย",
  "days": [ 8 ช่อง เรียง อาทิตย์ จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ พุธกลางคืน ],
  "animals": [ 12 ช่อง เรียง ชวด ฉลู ขาล เถาะ มะโรง มะเส็ง มะเมีย มะแม วอก ระกา จอ กุน ],
  "numbers": { "1": "…", "2": "…", …, "9": "…" }
}
```
ช่องใน `days`:
| คีย์ | ที่มา | เนื้อหา |
|---|---|---|
| birthDay, planet, todayRole, theme, stars | plan.js | ใส่ตามนั้นตรง ๆ |
| luckyColor, powerColor, supportColor, avoidColor, luckyNumber | plan.js | ใส่ตามนั้นตรง ๆ |
| headline | เขียน | หัวเรื่องสั้น 4–10 คำ ตรงกับภูมิ |
| overall | เขียน | ภาพรวม 3–4 ประโยค (ราว 150–260 ตัวอักษร) |
| work / money / love / health | เขียน | อย่างละ 2–3 ประโยค (ราว 100–180 ตัวอักษร) |
| tip | เขียน | ข้อแนะนำสั้น ๆ 1 วลี ทำได้จริงวันนี้ |

ช่องใน `animals`: `animal`, `relation` มาจาก plan.js · `text` เขียน 1–2 ประโยค (ราว 60–140 ตัวอักษร) ตาม relation ขึ้นต้นด้วยชื่อวัน เช่น "วันนี้เป็นวันชงของคนปีชวด …"
`numbers`: เขียนเลขละ 1–2 ประโยค (ราว 60–140 ตัวอักษร) บอกว่าวันนี้เหมาะกับอะไรสำหรับคนที่ได้เลขนั้น

วิธีที่ปลอดภัย: เขียนข้อความลงไฟล์ชั่วคราว แล้วใช้ node รวมกับผลของ plan.js ออกมาเป็นไฟล์จริง (ห้ามพิมพ์ช่องที่มาจาก plan.js เอง)

## ตรวจก่อน push
- JSON parse ได้ · `date` ตรงวันที่ · `days` ครบ 8 ช่อง · `animals` ครบ 12 ช่อง · `numbers` มีคีย์ "1" ถึง "9" ครบ
- ทุกช่องที่มาจาก plan.js ตรงกับผลของ plan.js ทุกตัวอักษร · ทุกช่องที่ต้องเขียนไม่ว่าง
