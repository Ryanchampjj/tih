# ดวงรายวัน — ข้อมูลที่หน้า horoscope.html อ่าน

Routine ของ Claude เขียนทุกวันเวลา 00:01 น. (เวลาไทย) แล้ว push เข้า main — GitHub Pages ขึ้นเว็บเอง

## ไฟล์ที่ต้องเขียนทุกวัน
- `horoscope/YYYY-MM-DD.json` — วันที่ตามเวลาไทย (UTC+7) ของวันที่เพิ่งเริ่ม
- `horoscope/today.json` — เนื้อหาเดียวกันทุกตัวอักษร (หน้าเว็บอ่านไฟล์นี้)
- ถ้าไฟล์วันนั้นมีอยู่แล้ว ไม่ต้องเขียนทับ แค่เช็กว่า today.json ตรงกัน
- ลบไฟล์รายวันที่เก่ากว่า 30 วันทิ้ง (เก็บ today.json ไว้เสมอ)

## รูปแบบ
```json
{
  "date": "2026-09-26",
  "days": [ 7 ช่อง เรียง อาทิตย์ จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ ]
}
```
แต่ละช่อง:
| คีย์ | เนื้อหา |
|---|---|
| headline | หัวเรื่องสั้น 3–8 คำ |
| stars | 1–5 (ส่วนใหญ่ 3–5 · ไม่ให้ 1 เกินวันละ 1 วันเกิด) |
| overall | ภาพรวม 1–2 ประโยค |
| work / money / love / health | อย่างละ 1 ประโยค |
| luckyColor / avoidColor | ชื่อสีภาษาไทยคำเดียว |
| luckyNumber | ตัวเลข 2 หลักเป็นข้อความ เช่น "45" |
| tip | ข้อแนะนำสั้น ๆ 1 วลี |

## กติกาเนื้อหา
- ภาษาไทยภาษาพูด อ่านง่าย อบอุ่น ให้กำลังใจ ห้ามภาษาแบบ AI ห้ามอีโมจิ
- คนอ่านคือพนักงานโรงพยาบาล (พยาบาล แม่บ้าน ช่าง คนขับรถ ฝ่ายสำนักงาน) — เรื่องงานให้เข้ากับงานโรงพยาบาลได้
- ห้ามทำนายเรื่องร้ายแรง (เจ็บป่วยหนัก อุบัติเหตุ ความตาย เสียงาน) ห้ามแนะนำยา/การรักษา/ลงทุน/หวย
- ไม่ระบุเพศ ไม่โทษใคร ใช้ได้ทั้งคนโสดและคนมีคู่
- 7 วันเกิดต้องไม่ซ้ำกัน และไม่ซ้ำกับของเมื่อวาน (เปิดไฟล์เมื่อวานดูก่อนเขียน)
- JSON ต้อง parse ได้ (`node -e "JSON.parse(require('fs').readFileSync('horoscope/today.json','utf8'))"`)
