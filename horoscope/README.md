## หลักที่ใช้: ทักษาพยากรณ์ (ห้ามแต่งโครงเอง)
ส่วนที่เป็น "กติกา" คำนวณด้วย `node horoscope/plan.js <วันที่>` เสมอ ห้ามคิดเอง:
- `todayPlanet` ดาวของวันนี้ · `todayRole` ดาววันนี้ตกภูมิไหนของคนเกิดวันนั้น (บริวาร อายุ เดช ศรี มูละ อุตสาหะ มนตรี กาลกิณี)
- `theme` เรื่องเด่นของภูมินั้น · `stars` ระดับดวงตามภูมิ
- `luckyColor` (สีดาวภูมิศรี) · `powerColor` (เดช) · `supportColor` (มนตรี) · `avoidColor` (กาลกิณี) · `luckyNumber` (เลขดาวเดช+ศรี)

**ส่วนที่เขียนเอง** = ข้อความทั้งหมด ต้องเล่าตามภูมิของวันนั้น เช่น
- ภูมิศรี → เรื่องโชคลาภ เงิน เสน่ห์ เด่น · ภูมิเดช → ความมั่นใจ การเป็นผู้นำ · ภูมิมนตรี → ผู้ใหญ่/คนช่วยเหลือ
- ภูมิบริวาร → คนรอบตัว ทีม ครอบครัว · ภูมิอายุ → สุขภาพ ความสบายใจ · ภูมิมูละ → บ้าน ทรัพย์สิน การออม
- ภูมิอุตสาหะ → งานหนัก ต้องลงแรง แต่ได้ผล · ภูมิกาลกิณี → มีอุปสรรคเล็ก ๆ ให้ระวัง ใจเย็น (ห้ามขู่ ห้ามเรื่องร้ายแรง)
- `overall` ต้องบอกว่าดาววันนี้เข้าภูมิอะไร แล้วอธิบายเป็นภาษาคน

## ไฟล์ที่ต้องเขียนทุกวัน
- `horoscope/YYYY-MM-DD.json` — วันที่ตามเวลาไทย (UTC+7) ของวันที่เพิ่งเริ่ม
- `horoscope/today.json` — เนื้อหาเดียวกันทุกตัวอักษร (หน้าเว็บอ่านไฟล์นี้)
- ถ้าไฟล์วันนั้นมีอยู่แล้ว ไม่ต้องเขียนทับ แค่เช็กว่า today.json ตรงกัน
- ลบไฟล์รายวันที่เก่ากว่า 30 วันทิ้ง (เก็บ today.json · README.md · plan.js ไว้เสมอ)

## รูปแบบ
```json
{
  "date": "2026-09-26",
  "todayPlanet": "เสาร์",
  "days": [ 7 ช่อง เรียง อาทิตย์ จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ ]
}
```
แต่ละช่อง:
| คีย์ | ที่มา | เนื้อหา |
|---|---|---|
| birthDay, taksa, stars | plan.js (`birthDay`, `todayRole`, `stars`) | ใส่ตามนั้นตรง ๆ |
| luckyColor, powerColor, supportColor, avoidColor, luckyNumber | plan.js | ใส่ตามนั้นตรง ๆ |
| headline | เขียน | หัวเรื่องสั้น 4–10 คำ ตรงกับภูมิ |
| overall | เขียน | ภาพรวม 3–4 ประโยค (ราว 150–260 ตัวอักษร) |
| work / money / love / health | เขียน | อย่างละ 2–3 ประโยค (ราว 100–180 ตัวอักษร) |
| tip | เขียน | ข้อแนะนำสั้น ๆ 1 วลี ทำได้จริงวันนี้ |

วิธีที่ปลอดภัย: เขียนข้อความลงไฟล์ชั่วคราว แล้วใช้ node รวมกับผลของ plan.js ออกมาเป็นไฟล์จริง (ห้ามพิมพ์ช่องที่มาจาก plan.js เอง)

## กติกาเนื้อหา
- ภาษาไทยภาษาพูด อ่านง่าย อบอุ่น ให้กำลังใจ ห้ามภาษาแบบ AI ห้ามอีโมจิ
- คนอ่านคือพนักงานโรงพยาบาล (พยาบาล แม่บ้าน ช่าง คนขับรถ ฝ่ายสำนักงาน) — เรื่องงานให้เข้ากับงานโรงพยาบาลได้
- ห้ามทำนายเรื่องร้ายแรง (เจ็บป่วยหนัก อุบัติเหตุร้ายแรง ความตาย เสียงาน) ห้ามแนะนำยา/การรักษา/ลงทุน/หวย
- ไม่ระบุเพศ ไม่โทษใคร ใช้ได้ทั้งคนโสดและคนมีคู่
- ภูมิวนซ้ำทุกสัปดาห์ แต่ข้อความต้องไม่ซ้ำกับของสัปดาห์ก่อนและของเมื่อวาน (เปิดไฟล์เก่าดูก่อนเขียน)
- JSON ต้อง parse ได้ มี days ครบ 7 ช่อง และช่องจาก plan.js ตรงกับผลของ plan.js ทุกช่อง
